# コード生成計画

## 対象

`resonance-tests` は、共鳴マップ、バトルトランザクション、および画面投影の受け入れ条件を自動検証する。

## 実装方針

1. 15セル、0〜10クランプ、元コストの最大3、および減衰をドメインテストで検証する。
2. クリーチャーの対象レーン加算、スペルの全レーン加算、スペル固有効果未実行を `GameEngine` 経由で検証する。
3. 火・水・風・光・闇の各効果、レーン別のターン使用状態とリセット、公開ビューおよび UI 表示を追加で検証する。

## 検証

- `npm test` を実行する。
- `npm run typecheck` を実行する。
