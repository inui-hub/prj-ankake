# コード生成計画

## 対象

`resonance-ui` は、バトル画面に共鳴値と関連状態を表示する。

## 実装方針

1. `PublicBattleView.playerResonance` を `BattleInfoPanels` のプレイヤー情報へ投影する。
2. レーンごとに5属性の値を安定した `data-testid` を持つコンテナ内へ表示する。
3. 機能設計にあるプレイヤー/CPU 切替、使用状態、属性効果説明、水の使用ボタンは、実装済み UI との差分として確認対象に残す。

## 検証

- 型検査で `PublicBattleView` と UI コンポーネント間の契約を確認する。
- UI テストが追加される場合は、プレイヤー共鳴表示と CPU 側の表示・非操作性を検証する。
