# コード生成計画

## 対象

`resonance-domain` は、基本ルール仕様書の §24〜§26 に従う属性共鳴をバトルドメインへ追加する。

## 実装方針

1. 各プレイヤーに左・中央・右 × 5属性の 15 値マップと、レーン単位の水・風・闇のターン使用状態を保持する。
2. カードの元コストから `min(cost, 3)` を求め、クリーチャーは召喚先レーン、スペルは全レーンへ加算する。スペル固有効果は解決しない。
3. スタンバイで（初回開始を除き）全値を 1 減衰し、0〜10 に収める。
4. 5以上を有効条件として、火の攻撃補正、水の移動補正、風のコスト軽減、光の攻撃終了時回復、闇の破壊時トークンを適用する。
5. 公開バトルビューとバトル画面にプレイヤー共鳴値を投影する。

## 検証

- 3×5マップ、クランプ、元コスト上限、スペル全レーン加算を単体テストに追加する。
- 全テストと全ワークスペースの型検査を実行する。
