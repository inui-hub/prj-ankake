# コード生成計画

## 対象

`resonance-integration` は、カード使用・ターン進行・公開ビュー・CPU コマンド選択の既存経路に共鳴状態を統合する。

## 実装方針

1. クリーチャー召喚時は召喚先レーン、スペル発動時は全レーンの共鳴を元コスト（最大3）で更新する。スペルの固有効果は解決しない。
2. スタンバイ開始時に初回を除いて共鳴を減衰し、水・風・闇のレーン別使用状態をリセットする。
3. 火・水・風・光・闇のしきい値効果を、攻撃・移動・召喚コスト・攻撃終了・破壊の各経路へ接続する。
4. プレイヤー共鳴を `PublicBattleView` に投影し、新しい水の移動強化コマンドを CPU の順序キーでも扱えるようにする。

## 検証

- 既存の `battleResonance.test.ts` でカード使用による加算とスペルの固有効果未実行を確認する。
- `npm test` と `npm run typecheck` を実行する。
