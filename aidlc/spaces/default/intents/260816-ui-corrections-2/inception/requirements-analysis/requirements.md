# UI修正要件

## Intent Analysis

プレイヤーがデッキ構築と対戦を迷わず操作できるよう、`ui_points.md` の言語、並び順、盤面識別、カード情報、共鳴操作に関する指摘を、既存の React UI と公開対戦投影の境界を保ったまま解消する。

## Functional Requirements

### FR-1: 言語切替

- メニュー右上に日本語／英語の切替ボタンを置き、日本語を初期値とする。切替状態は実行中の UI 状態だけに保持し、保存・次回起動への復元は行わない。
- 翻訳対象はゲーム内のすべてのプレイヤー向け画面、ダイアログ、起動・操作エラー、ラベル、ボタン、状態文言、およびカード効果テキストである。これにはメニュー、デッキ構築、対戦準備、対戦盤面、カード詳細を含む。管理・開発用の表示だけを対象外とする。
- 選択言語の訳文がない場合は日本語を表示する。効果の規則識別は表示文言に依存させない。

### FR-2: デッキ一覧の既定ソート

- デッキ構築画面で表示する全カード一覧の初期順とリセット後の順を `cost:asc` にし、表示名は日本語では「コスト昇順」、英語では `Cost up` とする。
- ユーザーが別のソートを選択した場合はその画面を開いている間だけ反映し、「リセット」操作、別画面への遷移後のデッキ構築画面への復帰、または新規起動時に `cost:asc` に戻す。ソート状態は保存しない。
- 同コストのカードは選択言語の名称を `Intl.Collator` で昇順比較し、同名の場合は安定したカード ID 昇順を副キーとする。

### FR-3: レーンと拠点の識別

- 対戦盤面の各レーンの空き・通常マス背景を、左 `#EAF3FF`、中央 `#FFF8E1`、右 `#FCECEC` とし、その上のレーン名・数値・アイコンは `#111827` で表示する。選択・水共鳴強調のマスにはレーン背景を残したまま `#111827` の 3px outline を追加する。
- 拠点マスは拠点名の代わりに拠点用アイコン画像と HP を表示する。制圧状態はマスの塗りを中立 `#6B7280`、味方 `#2563EB`、敵 `#DC2626` とし、その上の HP・アイコン前景は `#FFFFFF` とする。
- レーンと制圧状態は色だけに依存せず、マスに `data-lane` と `data-base-owner` を付け、レーン名と中立／味方／敵を識別するアイコンの accessible name を提供する。通常、選択、強調の各状態で、文字・アイコン前景対その直下の背景色を WCAG 2.1 の相対輝度式で測り、4.5:1 以上であることを受入試験で確認する。

### FR-4: カード詳細

- 手札と盤面にあるカードを対象とし、ポインタ hover 中は hover した 1 枚だけ、キーボードでは focus 中の 1 枚だけ、タッチでは最後にタップした 1 枚だけの詳細を開く。別カードへ hover／focus／タップした時は前の詳細を閉じて新しいカードへ切り替える。
- ポインタ詳細は対象カードと詳細のどちらかにポインタがある間に開き、両方から離れた時に閉じる。キーボード詳細は focus が対象カードから離れた時、タッチ詳細は同一カードの再タップ、別カードのタップ、盤面外のタップ、または Escape で閉じる。
- 詳細にはイラスト、カード名、攻撃、HP、移動力、効果を表示する。詳細は対象カードにアンカーし、既定は下側、下側が表示領域に収まらなければ上側、さらに収まらなければ表示領域内で左右へ移動して配置する。スクロール後はアンカー位置を再計算する。
- 詳細は非操作的な popover とし、盤面マスやカードの既存のクリック／キーボード操作を遮らず、対話要素をネストしない。

### FR-5: 共鳴値の表

- 対戦盤面に、行を `fire`、`water`、`wind`、`light`、`dark`、列を左・中央・右レーンとする 5×3 の表を表示する。
- 各セルは対応するレーン・属性の公開対戦 ViewModel の現在値を表示し、初期値または欠損値は `0` と表示する。公開 ViewModel が更新されるたびに表も更新する。

### FR-6: 水共鳴の直接選択

- 右上 UI のクリーチャー名選択を廃止し、`PublicBattleView.boardSquares[].occupant` の `canUseWaterResonance` が `true` のカードだけを盤面で強調する。`canUseWaterResonance` は、プレイヤー所有の盤面上のクリーチャーまたはクリーチャートークンであり、そのカードのレーンで水共鳴値が 5 以上、かつそのレーンの水共鳴を当該ターンに未使用である場合に `true` とする。
- 有効なカードはクリックまたはフォーカス後の Enter／Space で選択し、`{ type: "boostCreatureMovement", side: "player", creatureInstanceId }` を発行する。成功時は対象の一時移動力を `+1`、対象レーンの水共鳴使用済みを `true` にし、選択強調を解除する。水共鳴の使用済み状態はプレイヤーの次のターン開始時にレーンごとに `false` へ戻す。
- 対象なしは「このレーンには水共鳴の対象がありません」、水共鳴非活性は「このレーンの水共鳴は有効ではありません」、使用済みは「このレーンの水共鳴はこのターンに使用済みです」、その他の検証失敗は検証結果の理由を、選択言語で表示する（訳文がなければ日本語）。これらの失敗、取消、別操作はコマンドを実行せず、強調を解除し、ゲーム状態を変更しない。

## Non-Functional Requirements

- UI は既存の `PublicBattleView`／`BattleCardView` を表示の唯一の境界として用い、raw `BattleState` を表示層に公開しない。
- 日本語・英語の表示切替、ソート、hover、focus、タップ、および水共鳴の成功・失敗を自動テスト可能な状態として実装する。

## Constraints

- アプリケーションは React/Vite の `apps/web`、UI 部品の `packages/ui`、規則・公開投影の `packages/domain` の既存依存方向を維持する。
- 表示文言の追加は規則の同一性を変えず、カード効果の実行ロジックを翻訳文言で判定しない。

## Assumptions & Open Questions

None.

## Out of Scope

- 言語選択、ソート選択、または表示設定の永続化。
- 指定した 5 画面以外の新規画面・ゲーム規則・外部サービスの追加。
