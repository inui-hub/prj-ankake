# Project Ankake カード一覧 v1.1

- 収録カード：60枚（5属性×12枚）

- クリーチャーの数値は「攻撃力」「体力」を個別の列に記載する。
- スペルの攻撃力・体力は `-` とする。
- トークンはデッキ投入不可とする。

### トークン補足

- 「ルミナス・ウォール」は、光属性カードの効果によって場に出る。
- 「冥影の残滓」は、闇属性カードの効果や、闇共鳴しているレーン上で各ターン最初の味方クリーチャーが破壊されたとき、その破壊されたマスに出る。
- いずれもカード効果によって場に出るため、召喚として扱わず、共鳴値を増加させない。
